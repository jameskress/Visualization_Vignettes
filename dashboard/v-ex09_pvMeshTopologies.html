ParaView ex09 Mesh topologies

The same contour over four kinds of mesh; the point, cell and contour counts of each are checked.

Reads
Four generated meshes of the same wave field: a tetrahedral mesh, an adaptive-refinement (AMR) mesh, a polygonal surface, and a grid split into three blocks of unequal width.
Does
Contours each one (the surface as white isolines over its colours), removes AMR ghost cells (the overlap between refinement levels) and merges the blocks first.
Writes
Four PNGs, one per mesh, and a table of counts.
Checked
Per mesh: input points and cells, contour cells and value range against the baseline, and the blocks must really be unequal.
