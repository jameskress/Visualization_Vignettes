✓ ✗

x axis
the tool version, oldest on the left. Runs of one version sit in date order inside its band; hover for the date.
dot, bar
a dot is one run; a bar across a band is that version's median.
colour
the tool version, the same on every chart and page.
faded dot
not comparable with the latest run: an older revision of the vignette, or measured differently (older schema or scope).
revision
a change to a vignette's code. Times are compared only between runs of the same revision.
ring, outline
a drift warning: the run moved well outside its own history.
stale, retired
stale: no run in 30 days, or not on the pinned build. Retired: hardware that left the suite; its history is kept.
